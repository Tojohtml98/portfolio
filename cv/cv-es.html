Proyectos

Proyectos propios, con código público y aplicaciones en línea. Todas las cifras son verificables ejecutando el repositorio.

TaskFlow API — API REST de gestión de tareas y proyectos · TypeScript, Express, MongoDB, Jest, Docker · github.com/Tojohtml98/taskflow-api
  • Testing automatizado: 46 tests de integración en 4 suites, ejecutados contra una base MongoDB en memoria; la suite completa pasa en verde en ~10 s, con 97% de cobertura de sentencias y 99% de líneas.
  • Arquitectura por capas: cada módulo (auth, projects, tasks) separado en rutas, controlador, servicio, repositorio y modelo, de modo que la lógica de negocio no depende de Express ni de Mongoose.
  • Autenticación y seguridad: JWT con rotación de refresh tokens, hasheo de contraseñas con bcrypt, validación de entrada con Zod, cabeceras con Helmet y rate limiting en los endpoints de login y registro.
  • Integración continua y despliegue: pipeline en GitHub Actions que corre chequeo de tipos, tests y build en cada push y pull request; imagen Docker multi-etapa y despliegue en Render, en línea y respondiendo.
Turnero API — reservas de turnos con recordatorios automáticos · TypeScript, Express, MongoDB, node-cron, Nodemailer
  • Suite de 167 tests en 9 suites, todos en verde, cubriendo cálculo de disponibilidad, horarios comerciales, autenticación y el parser de fechas en lenguaje natural.
  • Motor de slots que calcula disponibilidad a partir de horarios y turnos ya tomados, más tareas programadas con cron para el envío automático de recordatorios por email.
Code Reviewer Agent — CLI de revisión de código con IA · Node.js, Claude Agent SDK · github.com/Tojohtml98/code-reviewer-agent
  • Herramienta de línea de comandos construida sobre el SDK de agentes de Anthropic: toma un diff de git y devuelve observaciones sobre bugs, seguridad y claridad. Ejemplo concreto de integrar IA en el flujo de trabajo manteniendo la decisión final del lado humano.
Frontends y aplicaciones desplegadas · React, Vite, Firebase
  • Cliente de TaskFlow en React consumiendo la API propia (taskflow-client-nu.vercel.app), portfolio personal en React + Vite y un e-commerce con React y Firebase. Cuatro aplicaciones actualmente en línea entre Render y Vercel.
